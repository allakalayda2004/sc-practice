Команда git diff показывает разницу между состояниями файлов, git log выводит список коммитов с историей, а git show отображает метаданные и изменения конкретного коммита

git  log -s показывает коммиты, где найдена указанная строка
git blame показал информацию кто и когда добавил код

Команда git restore восстанавливает файлы из индекса по умолчанию, а git restore --source позволяет указать конкретный источник (коммит, ветку или тег), откуда нужно взять версию файла. Правки бы пропали

Команда git revert безопаснее, потому что она не удаляет старые коммиты и не переписывает историю, а создает новый коммит, который отменяет прошлые изменения

Тег в Git — это статичная и неизменяемая метка для конкретного коммита, а ветка — это подвижный указатель, который автоматически сдвигается вперед при создании новых коммитов
