Команда git diff --staged показывает разницу между подготовленными к коммиту изменениями (staging area) и последним сделанным коммитом (HEAD)
Git — это программа для отслеживания изменений в коде на вашем компьютере, а GitHub — это сайт в интернете для хранения этого кода и командной работы
Команды git status, git diff и git diff --staged показывают состояние файлов и изменения в репозитории
